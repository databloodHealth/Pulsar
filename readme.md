> Tecnologias: HTML5 · CSS3 · JavaScript Vanilla
 
---
 
## Sobre o Projeto
 
O **HemoSystem** é uma aplicação web para gerenciamento de bancos de sangue, desenvolvida como TCC. O objetivo é centralizar o controle de doadores, estoque de sangue por tipo sanguíneo e atendimento a pacientes que necessitam de transfusão com urgência.
 
Esta primeira versão é **100% estática**, sem backend — toda a persistência de dados são mockados.
